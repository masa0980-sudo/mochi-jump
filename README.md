# もちジャンプ

もちのようにぷにぷに弾みながら進む、短いステージのブラウザ2Dアクション。`index.html` 一枚で完結しています。

公開URL: https://masa0980-sudo.github.io/mochi-jump/

## 遊び方

← → で移動、ジャンプボタン(または スペース / ↑)で跳ぶ。押しっぱなしで高くジャンプできる。
落とし穴に落ちても直前の安全な場所からやり直せるので、気軽に何度も挑戦できる。
とげに触れても同様にやり直しになる。ゴールの臼(うす)にたどり着けばクリア。
道中の「きなこ」を集めるとおまけのスコアになる(クリアには必須ではない)。

## プレイ回数の記録

姉妹プロジェクト([Rhythm_game](https://github.com/masa0980-sudo/rhythm_game) など)と同じFirestore(`rythm-game-mo`プロジェクト)を
共有のカウンター保存先として使い、プレイ回数を記録・表示している。詳細はCLAUDE.mdを参照。
